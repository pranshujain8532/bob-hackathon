# Nexus Causal Intelligence Platform - Project Analysis

## 🎯 Project Overview

**Nexus** is a sophisticated **Causal Intelligence Platform** that analyzes software repositories to extract and visualize **Decision Provenance Records (DPRs)**. It creates a **Causal Temporal Graph (CTG)** showing how architectural decisions relate to each other, tracks assumption decay, and identifies technical debt risks.

### Core Capabilities:
- **Repository Analysis**: Clones and analyzes any GitHub repository (Python, JavaScript, etc.)
- **LLM-Powered DPR Generation**: Uses Gemini or WatsonX to extract architectural decisions
- **Graph Database Storage**: Loads DPRs into Neo4j for causal relationship querying
- **Vector Search**: Optional Weaviate integration for semantic search
- **Risk Analysis**: Identifies decay alerts, blast radius, and knowledge concentration
- **Interactive Dashboard**: Web-based visualization of the CTG
- **REST API**: FastAPI backend for programmatic access

## 🎯 Key Features

### 1. **Decision Provenance Records (DPRs)**
Each DPR captures:
- Decision title and description
- Component (e.g., Authentication, Storage)
- Assumptions and constraints
- Blast radius estimate (critical/high/medium/low)
- Decay risk (high/medium/low)
- Active workarounds (technical debt)
- Related files and commits

### 2. **Causal Temporal Graph (CTG)**
Relationships between DPRs:
- `CONSTRAINS` - Decision A limits decision B
- `ENABLES` - Decision A makes B possible
- `REQUIRES` - Decision A needs B
- `ASSUMPTION_OF` - Decision A assumes B holds
- `TEMPORAL_PRECEDES` - Decision A came before B

### 3. **Decay Monitoring**
Tracks when assumptions break:
- Already decaying vs. monitoring
- Evidence of decay
- Recommended SQL queries to monitor

### 4. **Risk Analysis**
- Composite risk scores
- Knowledge concentration (bus factor)
- Blast radius impact
- Workaround proliferation

## 🛠️ Troubleshooting

### Issue: "No LLM provider configured"
**Solution:** Set API key:
```bash
export GEMINI_API_KEY="your-key"
```

### Issue: "Failed to connect to Neo4j"
**Solution:** Start Neo4j:
```bash
docker run -p7474:7474 -p7687:7687 neo4j:community
```

### Issue: "nexus_data.json not found"
**Solution:** Run analysis first:
```bash
python repo_analyzer.py https://github.com/some/repo
```

### Issue: Module not found
**Solution:** Install missing dependencies:
```bash
pip install fastapi uvicorn weaviate-client
```
